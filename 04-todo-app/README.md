# Todo App

A Todo application built with React to practice state management
using the `useState` hook.

## Features

- Add new tasks
- Delete tasks
- Mark tasks as complete/incomplete


## What I Learned

- What state is in React
- Why normal variables are not enough for UI updates
- `useState`
- Setter functions
- Re-rendering
- Previous-state updates
- State with arrays
- State with objects
- Updating objects inside arrays
- `map()` for updating state
- `filter()` for removing items
- Passing state and functions between components

## Components

- `App` - Manages todo state and todo operations
- `Todos` - Renders the list of todos
- `Todo` - Displays an individual todo

## Tech Stack

- React
- JavaScript
- JSX
- Tailwind CSS
