# Product Listing

A product listing application built with React. It displays
products from an array and uses filtering and conditional rendering
to show different product states.

## Features

- Display products from an array
- Filter products by category
- Display product name, category, price, and rating
- Show stock status
- Different styles for in-stock and out-of-stock products
- Empty products state

## Components

- `App` - Stores product data and manages the filter
- `Products` - Renders the product list and handles the empty state
- `Card` - Displays individual product information
- `Filter` -  Provides category/filter controls and updates the selected filter
