# Personal Profile Page

A simple personal profile page built with React and JSX.

This is my first React learning project, created to understand
the fundamentals of building user interfaces with reusable components.

## About the Project

The page contains:

- Header
- About Me section
- Projects section
- Contact section

The project uses reusable React components to structure the UI.

## What I Learned

- React basics
- JSX
- Functional components
- JSX expressions
- Component nesting
- Component composition
- Props
- `children` prop
- Reusable components
- Basic React project setup

## Components

- `Head` - Displays the header and personal information
- `Profile` - Displays information about me
- `Project` - Displays my projects
- `Contact` - Displays contact information
- `Section` - Reusable section wrapper

## Tech Stack

- React
- JavaScript
- JSX
- Tailwind CSS
