# React Router Practice

A small project built to practice React Router concepts.

## Concepts Learned
- Nested Routes and Layout Routes
- Index Routes and Outlet
- NavLink and Active Styling
- URL Parameters with useParams
- Search Params with useSearchParams
- Sharing Data with useOutletContext
- Not Found Routes

## Tech Stack
- React
- React Router
- Tailwind CSS

## Learning Goal
Understanding how routing, nested layouts, URL parameters,
and URL-based filtering work in React applications.
