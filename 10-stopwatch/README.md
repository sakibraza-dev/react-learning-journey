# Stopwatch

A simple stopwatch built with React and JSX.

I built this project to understand how `useRef` works and how it can be used with `setInterval` to control a timer.

## About the Project

The stopwatch has three buttons:

- Start the stopwatch
- Stop the stopwatch
- Reset the stopwatch

The time is displayed in `HH:MM:SS` format.

## What I Learned

- `useRef` and `useState`
- How `setInterval` works
- How to stop an interval using `clearInterval`
- Why the interval ID is stored in a ref
- How to update state using the previous value
- Passing data and functions between components

## Tech Used

- React
- JSX
- Tailwind CSS
