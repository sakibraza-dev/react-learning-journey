# Student Card Gallery

A simple student card gallery built with React to practice passing
data between components and rendering multiple cards from an array.

## What I Learned

- Parent-to-child data flow
- Destructuring props
- Passing arrays as props
- Passing objects as props
- Functions as props
- Rendering lists with `map()`
- Using keys when rendering lists
- Reusable components

## Features

- Displays multiple student cards
- Student information is stored in an array
- Reusable StudentCard component
- Select button using a function passed as a prop

## Components

- `App` - Stores student data and handles the student selection function
- `Card` - Receives the student array and renders multiple cards
- `StudentCard` - Displays individual student information

## Tech Stack

- React
- JavaScript
- JSX
- Tailwind CSS
