# Interactive Counter

An interactive counter application built with React to practice
handling user events and managing state.

## Features

- Increase the counter
- Decrease the counter
- Reset the counter
- Set a custom step value
- Set the counter to a custom number
- Prevent form submission from refreshing the page

## What I Learned

- `onClick`
- `onChange`
- `onSubmit`
- Event object
- `event.preventDefault()`
- Handling input values
- Updating state based on previous state
- Using multiple pieces of state

## How It Works

The counter can be increased or decreased using the selected step value.

For example:

- Step = 5
- Increase → counter increases by 5
- Decrease → counter decreases by 5

The counter can also be directly set to a custom value using the form.

- React
